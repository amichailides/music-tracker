Music Tracker 🎸

Ένα πρακτικό project σε Java για τη διαχείριση μαθητών και των μουσικών τους μαθημάτων. Το έφτιαξα για να μάθω στην πράξη πώς οργανώνεται μια εφαρμογή που διαχειρίζεται δεδομένα (CRUD), προσπαθώντας να εφαρμόσω καθαρό κώδικα και μια σωστή, βασική δομή.

🕹️ Λειτουργίες
Η εφαρμογή επιτρέπει την πλήρη διαχείριση των δεδομένων:


Προσθήκη & Ενημέρωση: Μπορείς να δημιουργήσεις νέους μαθητές και μαθήματα ή να αλλάξεις τα στοιχεία τους χρησιμοποιώντας κατάλληλα Update DTOs.


Προβολή: Εκτύπωση λίστας μαθητών και του ιστορικού των μαθημάτων τους με καθαρή μορφοποίηση.


Έλεγχος & Καθαρισμός: Πριν την αποθήκευση, τα δεδομένα περνάνε από Validators (για εγκυρότητα) και Sanitizers (για καθαρισμό από λάθος κενά ή χαρακτήρες) σε πεδία όπως emails, ονόματα και τηλέφωνα.
